Crab Shell Biometric Width Estimation

Author: Matthew Nader Fawzy | Communication & Information Engineer

Python Detectron2 PyTorch Instance Segmentation Biometrics

Overview

Engineered an accurate non-invasive biometric measurement system to estimate the carapace width of marine crabs from underwater video streams. The system replaces manual specimen capture with automated optical analysis, aiding marine conservation and ecological surveying.

Engineering Pipeline

  • Instance Segmentation: Fine-tuned Detectron2 Mask R-CNN architectures to isolate complex organic silhouettes against cluttered seabed backgrounds.
  • Principal Component Analysis (PCA): Determines the major biometric axis of the segmented mask to find the true morphological carapace width.
  • Laser Scale Calibration: Integrates parallel laser scaler point detection to calculate dynamic pixel-to-millimeter conversion ratios regardless of ROV distance.
